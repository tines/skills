# Daily briefing

Gather current information from the user’s relevant connectors before summarizing it.

Prioritize:

- Time-sensitive meetings, deadlines, incidents, and requests
- Work explicitly assigned to the user
- Threads or reviews waiting on the user
- Recent changes that alter today’s priorities

Group related items, identify the source of each fact, and distinguish confirmed commitments from suggestions. For meeting preparation, include the purpose, participants, recent related work, unresolved questions, and a short preparation checklist.
